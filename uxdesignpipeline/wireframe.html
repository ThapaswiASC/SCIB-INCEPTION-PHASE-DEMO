How to Create Your First Task
Getting Started • 3 min read • Beginner level
Article Content

Creating your first task is the foundation of organizing your work in Digital Product Experience. This guide will walk you through the process step by step.

Step 1: Navigate to Task Creation

You can create a task from several locations:

  • Click the "+ Add Task" button in any project
  • Use the "+ Quick Add Task" button in My Tasks dashboard
  • Press Ctrl+N (Cmd+N on Mac) from anywhere in the app
Step 2: Fill in Task Details

The task creation form includes several important fields:

Task Title
Required - Be specific and actionable
Description
Optional - Add context and requirements
Project
Required - Choose the relevant project
Due Date
Optional - Set realistic deadlines
Priority
Optional - High, Medium, or Low
Step 3: Assign and Save

Choose who should work on this task (you can assign it to yourself or team members) and click "Create Task" to save it.

Pro Tip
Use templates for recurring task types to save time. You can create templates from the project settings.
