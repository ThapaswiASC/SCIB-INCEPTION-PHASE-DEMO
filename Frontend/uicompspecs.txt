### 4. COMPONENT IMPLEMENTATION

#### 4.1 KanbanBoardComponent

Component Type: Feature

Mapped From A1: Main container for three-column kanban layout

Purpose: Render and manage the complete kanban board with drag-and-drop functionality

Parent: MainContentComponent

Children:
- KanbanColumnComponent (3 instances)
- AddTaskModalComponent
- TaskDetailComponent

Dependencies:
- TaskService (API calls)
- DragDropService (drag and drop)
- StateManagementService (board state)

Library Components Used:
- Grid Component → Layout container
- Button Component → Action buttons
- Modal Component → Task modals

TypeScript Specification:

Inputs:
- columns: KanbanColumn[] (column configuration)
- tasks: Task[] (task data)
- loading: boolean (loading state)
- error: string | null (error message)

Outputs:
- onTaskMove: EventEmitter<TaskMoveEvent> (task status change)
- onTaskSelect: EventEmitter<Task> (task selection)
- onTaskCreate: EventEmitter<void> (new task creation)

State:
- selectedTask: Task | null (currently selected task)
- draggedTask: Task | null (task being dragged)
- columnData: KanbanColumn[] (column state)
- isModalOpen: boolean (modal visibility)

Methods:
- initializeBoard() → void (setup board data)
- handleTaskDrop(event: DragEvent) → void (handle drop events)
- openTaskModal(task?: Task) → void (open task creation/edit modal)
- refreshBoard() → Promise<void> (reload board data)

HTML STRUCTURE (PSEUDO CODE ONLY):

<div class="kanban-board-container" role="region" aria-label="Kanban Board">
  <div class="board-header">
    <h1>Kanban Board</h1>
    <Button variant="primary" onClick="openTaskModal">Add Task</Button>
  </div>
  
  <div class="kanban-grid" [grid-template-columns]="repeat(3, 1fr)">
    <KanbanColumn 
      *ngFor="let column of columns" 
      [column]="column" 
      [tasks]="getTasksForColumn(column.id)"
      (onTaskDrop)="handleTaskDrop($event)"
    />
  </div>
  
  <AddTaskModal 
    [isOpen]="isModalOpen" 
    [task]="selectedTask"
    (onSubmit)="handleTaskSubmit($event)"
    (onCancel)="closeModal()"
  />
  
  <div *ngIf="error" class="error-message" role="alert">
    {{ error }}
  </div>
</div>

CSS SPECIFICATION:

Layout:
- .kanban-board-container: display: flex, flex-direction: column, height: 100vh
- .kanban-grid: display: grid, grid-template-columns: repeat(3, 1fr), gap: 1rem

Spacing:
- padding: 1rem
- gap: 1rem between columns

Component Styles:
- .board-header: flex layout with space-between alignment
- .error-message: red background, padding, border-radius

Responsive:
- Desktop (>1024px): 3 columns side by side
- Tablet (768px-1024px): 2 columns with scroll
- Mobile (<768px): single column stack

API INTEGRATION:
- initializeBoard() → GET /api/tasks → load all tasks
- handleTaskDrop() → PUT /api/tasks/{id} → update task status
- refreshBoard() → GET /api/tasks → reload board data

ERROR HANDLING:
- API failure → show error snackbar with retry option
- Validation error → inline form validation messages
- Network error → offline mode indicator

INTERACTION FLOW:

User Action → UI → API:
- Drag task → optimistic UI update → PUT /api/tasks/{id} → confirm/rollback
- Click "Add Task" → open modal → fill form → POST /api/tasks → refresh board
- Click task card → open detail view → GET /api/tasks/{id} → display details

#### 4.3 TaskCardComponent

Purpose: Display task information with drag capability and quick actions

Inputs:

- draggable: boolean (drag enabled)

Outputs:

State:
- isSelected: boolean (selection state)
- isEditing: boolean (edit mode)
- isHovered: boolean (hover state)

Methods:
- handleClick() → void
- handleEdit() → void
- handleDelete() → void
- formatDueDate(date: string) → string

HTML STRUCTURE (PSEUDO CODE ONLY):

<Card 
  class="task-card" 
  [class.selected]="isSelected"
  [class.overdue]="isOverdue"
  [draggable]="draggable"
  (click)="handleClick()"
  (dragstart)="handleDragStart($event)">
  
  <div class="task-header">
    <h4 class="task-title">{{ task.title }}</h4>
    <Badge [variant]="getPriorityVariant(task.priority)">

        [name]="task.assignee.name"
        size="sm"
      />
      <span>{{ task.assignee.name }}</span>
    </div>
    
    <div class="due-date" *ngIf="task.dueDate">
      <Icon name="calendar" />
      <span [class.overdue]="isOverdue">{{ formatDueDate(task.dueDate) }}</span>
    </div>
  </div>
  
  <div class="task-actions" *ngIf="isHovered">
    <Button variant="ghost" size="sm" (onClick)="handleEdit()">
      <Icon name="edit" />
    </Button>
    <Button variant="ghost" size="sm" (onClick)="handleDelete()">
      <Icon name="delete" />
    </Button>
  </div>
</Card>

CSS SPECIFICATION:

Layout:
- .task-card: display: flex, flex-direction: column, cursor: pointer
- .task-header: flex layout with space-between
- .task-metadata: flex layout with space-between

Spacing:
- padding: 1rem
- margin-bottom: 0.5rem
- gap: 0.5rem between elements

Component Styles:
- .task-card: border-radius, box-shadow, hover effects
- .selected: border highlight, background change

- .task-actions: absolute positioning, fade-in animation

Responsive:
- Mobile: reduce padding, stack metadata vertically

API INTEGRATION:
- handleEdit() → navigate to edit view → PUT /api/tasks/{id}
- handleDelete() → confirmation → DELETE /api/tasks/{id}

ERROR HANDLING:
- Delete failure → show error message, revert UI
- Edit failure → show validation errors

INTERACTION FLOW:

User Action → UI → API:
- Click card → select task → navigate to detail view → GET /api/tasks/{id}
- Click edit → open edit modal → submit changes → PUT /api/tasks/{id}
- Click delete → show confirmation → confirm → DELETE /api/tasks/{id}

#### 4.4 HeaderComponent

Component Type: Layout

Mapped From A1: Top navigation with search and user actions

Purpose: Provide global navigation, search functionality, and user account access

Parent: AppComponent

Children:
- Input Component (search)
- Avatar Component (user)
- Button Component (actions)

Dependencies:
- SearchService
- AuthService
- NotificationService

Library Components Used:
- Input Component → Search field
- Button Component → Action buttons
- Avatar Component → User avatar
- Dropdown Component → User menu

TypeScript Specification:

Inputs:
- user: User (current user data)
- notifications: Notification[] (user notifications)
- searchPlaceholder: string (search placeholder text)

Outputs:
- onSearch: EventEmitter<string> (search query)
- onNotificationClick: EventEmitter<void> (notification panel)
- onSettingsClick: EventEmitter<void> (settings navigation)
- onLogout: EventEmitter<void> (user logout)

State:
- searchQuery: string (current search)
- isSearchFocused: boolean (search focus state)
- showNotifications: boolean (notification panel visibility)
- showUserMenu: boolean (user menu visibility)

Methods:
- handleSearch(query: string) → void
- toggleNotifications() → void
- toggleUserMenu() → void
- handleLogout() → void

HTML STRUCTURE (PSEUDO CODE ONLY):

<header class="app-header">
  <div class="header-content">
    <div class="search-section">
      <Input 
        type="search"
        [placeholder]="searchPlaceholder"
        [value]="searchQuery"
        (onInput)="handleSearch($event)"
        (onFocus)="isSearchFocused = true"
        (onBlur)="isSearchFocused = false"
      />
    </div>
    
    <div class="header-actions">
      <Button 
        variant="ghost" 
        [badge]="notifications.length"
        (onClick)="toggleNotifications()">
        <Icon name="bell" />
      </Button>
      
      <Button variant="ghost" (onClick)="onSettingsClick.emit()">
        <Icon name="settings" />
      </Button>
      
      <Dropdown [isOpen]="showUserMenu" (onToggle)="toggleUserMenu()">
        <Avatar 
          [src]="user.avatar"
          [name]="user.name"
          size="md"
          slot="trigger"
        />
        
        <div slot="content" class="user-menu">
          <div class="user-info">
            <span class="user-name">{{ user.name }}</span>
            <span class="user-email">{{ user.email }}</span>
          </div>
          <Button variant="ghost" (onClick)="onSettingsClick.emit()">Settings</Button>
          <Button variant="ghost" (onClick)="handleLogout()">Logout</Button>
        </div>
      </Dropdown>
    </div>
  </div>
  
  <div *ngIf="showNotifications" class="notification-panel">
    <!-- Notification list -->
  </div>
</header>

CSS SPECIFICATION:

Layout:
- .app-header: display: flex, align-items: center, position: sticky, top: 0
- .header-content: display: flex, justify-content: space-between, width: 100%
- .header-actions: display: flex, align-items: center, gap: 1rem

Spacing:
- padding: 1rem 2rem
- gap: 1rem between action items

Component Styles:
- .app-header: background: white, border-bottom, z-index: 100
- .search-section: flex: 1, max-width: 400px
- .notification-panel: absolute positioning, dropdown shadow

Responsive:
- Mobile: hide search on small screens, collapse to hamburger menu

API INTEGRATION:
- handleSearch() → debounced GET /api/tasks?search={query}
- Notification polling → GET /api/notifications

ERROR HANDLING:
- Search API failure → show "Search unavailable" message
- Notification load failure → show error badge

INTERACTION FLOW:

User Action → UI → API:
- Type in search → debounce → API call → update results
- Click notifications → load notifications → display panel
- Click settings → navigate to settings page

#### 4.6 AddTaskModalComponent

Component Type: Feature

Mapped From A1: Modal for creating new tasks

Purpose: Provide form interface for task creation and editing

Parent: KanbanBoardComponent

Children:
- Input Component (form fields)
- Button Component (actions)
- Dropdown Component (selects)

Dependencies:
- TaskService
- ValidationService
- UserService (for assignee selection)

Library Components Used:
- Modal Component → Container
- Input Component → Form fields
- Button Component → Actions
- Dropdown Component → Select fields

TypeScript Specification:

Inputs:
- isOpen: boolean (modal visibility)
- task: Task | null (task for editing, null for creation)
- initialData: Partial<Task> (pre-filled data)

Outputs:
- onSubmit: EventEmitter<Task> (form submission)
- onCancel: EventEmitter<void> (modal cancellation)
- onFieldChange: EventEmitter<{field: string, value: any}> (field updates)

State:
- formData: TaskFormData (form state)
- validationErrors: ValidationErrors (form validation)
- isSubmitting: boolean (submission state)
- availableUsers: User[] (assignee options)

Methods:
- initializeForm() → void
- validateForm() → boolean
- handleSubmit() → Promise<void>
- handleCancel() → void
- loadUsers() → Promise<void>

HTML STRUCTURE (PSEUDO CODE ONLY):

<Modal 
  [isOpen]="isOpen" 
  [title]="task ? 'Edit Task' : 'Create New Task'"
  (onClose)="handleCancel()">

    <div class="form-group">
      <label for="title">Task Title *</label>
      <Input 
        id="title"
        type="text"
        [value]="formData.title"
        [error]="validationErrors.title"

      />
    </div>
    
    <div class="form-group">
      <label for="description">Description</label>
      <Input 
        id="description"
        type="textarea"
        [value]="formData.description"
        [error]="validationErrors.description"
        (onInput)="updateField('description', $event)"
        rows="4"
      />
    </div>
    
    <div class="form-row">
      <div class="form-group">
        <label for="priority">Priority</label>
        <Dropdown 
          id="priority"
          [value]="formData.priority"
          [options]="priorityOptions"
          (onSelect)="updateField('priority', $event)"
        />
      </div>
      
      <div class="form-group">
        <label for="assignee">Assignee</label>
        <Dropdown 
          id="assignee"
          [value]="formData.assigneeId"
          [options]="userOptions"
          (onSelect)="updateField('assigneeId', $event)"
        />
      </div>
    </div>
    
    <div class="form-group">
      <label for="dueDate">Due Date</label>
      <Input 
        id="dueDate"
        type="date"
        [value]="formData.dueDate"
        [error]="validationErrors.dueDate"
        (onInput)="updateField('dueDate', $event)"
      />
    </div>
    
    <div class="form-actions">
      <Button 
        type="button" 
        variant="secondary" 
        (onClick)="handleCancel()"
        [disabled]="isSubmitting">
        Cancel
      </Button>
      <Button 
        type="submit" 
        variant="primary" 
        [loading]="isSubmitting"
        [disabled]="!isFormValid">
        {{ task ? 'Update Task' : 'Create Task' }}
      </Button>
    </div>
  </form>
</Modal>
