4. COMPONENT IMPLEMENTATION

### 4.1 KanbanBoardComponent

Component Type: Feature

Mapped From A1: KanbanBoardComponent - Main kanban board container with three-column layout

Purpose: Primary container for kanban board functionality with three-column layout (To Do, In Progress, Done)

Parent: MainContentComponent

Children:
- KanbanColumnComponent (3 instances)
- AddTaskModalComponent
- TaskDetailComponent

Dependencies:
- TaskService
- KanbanService
- Angular CDK Drag Drop

Library Components Used:
- Card → Glass morphism container
- Button → Add task action
- Modal → Task creation/editing

TypeScript Specification

Inputs:
- loading: boolean
- error: string | null

Outputs:
- taskCreated: EventEmitter<Task>
- taskUpdated: EventEmitter<Task>
- taskDeleted: EventEmitter<string>

State:
- columns: KanbanColumn[]
- tasks: Task[]
- selectedTask: Task | null
- draggedTask: Task | null
- isAddModalOpen: boolean

Methods:
- ngOnInit() → Initialize board data
- loadTasks() → Fetch tasks from API
- onTaskMove(taskId: string, newColumnId: string) → Handle drag and drop
- onTaskSelect(task: Task) → Open task details
- onAddTask() → Open add task modal
- onTaskCreate(task: CreateTaskRequest) → Create new task

HTML STRUCTURE (PSEUDO CODE ONLY)

<div class="kanban-board-container">
  <div class="board-header">
    <h2>Kanban Board</h2>
    <button (click)="onAddTask()">Add Task</button>
  </div>
  
  <div class="kanban-columns" cdkDropListGroup>
    <app-kanban-column 
      *ngFor="let column of columns"
      [column]="column"
      [tasks]="getTasksForColumn(column.id)"
      [allowDrop]="true"
      (taskDrop)="onTaskMove($event.taskId, column.id)"
      (taskSelect)="onTaskSelect($event)">
    </app-kanban-column>
  </div>
  
  <app-add-task-modal
    [isOpen]="isAddModalOpen"
    (submit)="onTaskCreate($event)"
    (close)="isAddModalOpen = false">
  </app-add-task-modal>
  
  <app-task-detail
    *ngIf="selectedTask"
    [task]="selectedTask"
    (close)="selectedTask = null"
    (update)="onTaskUpdate($event)">
  </app-task-detail>
</div>

CSS SPECIFICATION

Layout:
- display: grid
- grid-template-columns: repeat(3, 1fr)
- gap: 1rem
- min-height: 100vh

Spacing:
- padding: 1rem
- gap: 1rem between columns

Component Styles:
- .kanban-board-container: main container with glass morphism
- .board-header: flex layout with title and actions
- .kanban-columns: grid layout for three columns

Responsive:
- Desktop (>1024px): 3 columns side by side
- Tablet (768px-1024px): 2 columns with scroll
- Mobile (<768px): 1 column with horizontal scroll

API INTEGRATION

- loadTasks() → GET /api/tasks → Load all tasks for board
- onTaskCreate() → POST /api/tasks → Create new task
- onTaskMove() → PUT /api/tasks/{id} → Update task status

ERROR HANDLING

- API failure → show error snackbar with retry option
- Validation error → inline form validation messages
- Network error → offline mode indicator

INTERACTION FLOW

User Action → UI → API
- Load board → ngOnInit → GET /api/tasks → populate columns
- Drag task → onTaskMove → PUT /api/tasks/{id} → update UI state
- Click add → onAddTask → open modal → POST /api/tasks → refresh board

### 4.2 KanbanColumnComponent

Component Type: Feature

Mapped From A1: KanbanColumnComponent - Individual column container for tasks

Purpose: Container for tasks in specific status column with drag and drop support

Parent: KanbanBoardComponent

Children:
- TaskCardComponent (multiple instances)

Dependencies:
- Angular CDK Drag Drop

Library Components Used:
- Card → Column container
- Badge → Task count indicator

TypeScript Specification

Inputs:
- column: KanbanColumn
- tasks: Task[]
- allowDrop: boolean

Outputs:
- taskDrop: EventEmitter<{taskId: string, columnId: string}>
- taskSelect: EventEmitter<Task>

State:
- isDropTarget: boolean
- taskCount: number

Methods:
- onTaskDrop(event: CdkDragDrop<Task[]>) → Handle task drop
- onTaskSelect(task: Task) → Emit task selection
- getTaskCount() → Calculate task count for column

HTML STRUCTURE (PSEUDO CODE ONLY)

<div class="kanban-column" 
     cdkDropList
     [cdkDropListData]="tasks"
     (cdkDropListDropped)="onTaskDrop($event)">
  
  <div class="column-header">
    <h3>{{ column.title }}</h3>
    <span class="task-count">{{ taskCount }}</span>
  </div>
  
  <div class="column-content">
    <app-task-card
      *ngFor="let task of tasks; trackBy: trackByTaskId"
      [task]="task"
      [draggable]="true"
      cdkDrag
      (select)="onTaskSelect(task)">
    </app-task-card>
  </div>
  
  <div class="column-footer" *ngIf="tasks.length === 0">
    <p class="empty-state">No tasks in {{ column.title }}</p>
  </div>
</div>

CSS SPECIFICATION

Layout:
- display: flex
- flex-direction: column
- min-height: 500px
- background: glass morphism effect

Spacing:
- padding: 1rem
- gap: 0.5rem between tasks

Component Styles:
- .kanban-column: flex container with glass background
- .column-header: flex layout with title and count
- .column-content: scrollable task list
- .empty-state: centered placeholder text

Responsive:
- Desktop: fixed width with scroll
- Tablet: flexible width
- Mobile: full width

API INTEGRATION

- None (receives data from parent KanbanBoardComponent)

ERROR HANDLING

- Drop validation → prevent invalid drops
- Empty state → show helpful message

INTERACTION FLOW

User Action → UI → API
- Drop task → onTaskDrop → emit to parent → API call in parent
- Click task → onTaskSelect → emit to parent → open task details

### 4.6 AddTaskModalComponent

Component Type: Feature

Mapped From A1: AddTaskModalComponent - Modal for creating new tasks

Purpose: Modal interface for creating new tasks with form validation

Parent: KanbanBoardComponent

Children:
- Form inputs
- Action buttons

Dependencies:
- Angular Reactive Forms
- Task service

Library Components Used:
- Modal → Container overlay
- Input → Form fields
- Button → Actions
- Avatar → User selection

TypeScript Specification

Inputs:
- isOpen: boolean
- users: User[]

Outputs:
- submit: EventEmitter<CreateTaskRequest>
- close: EventEmitter<void>

State:
- formData: CreateTaskRequest
- isSubmitting: boolean
- validationErrors: ValidationError[]
- selectedAssignee: User | null

Methods:
- onSubmit() → Validate and emit task creation
- onClose() → Close modal and reset form
- validateForm() → Check form validity
- resetForm() → Clear form data

HTML STRUCTURE (PSEUDO CODE ONLY)

<app-modal [isOpen]="isOpen" (close)="onClose()">
  <div class="modal-header">
    <h2>Create New Task</h2>
    <app-button variant="ghost" (click)="onClose()">✕</app-button>
  </div>
  
  <form class="task-form" (ngSubmit)="onSubmit()">
    <div class="form-group">
      <label for="title">Task Title</label>
      <app-input
        id="title"
        [(ngModel)]="formData.title"
        [error]="getFieldError('title')"
        required>
      </app-input>
    </div>
    
    <div class="form-group">
      <label for="description">Description</label>
      <textarea
        id="description"
        [(ngModel)]="formData.description"
        rows="3">
      </textarea>
    </div>
    
    <div class="form-group">
      <label for="assignee">Assignee</label>
      <select id="assignee" [(ngModel)]="formData.assigneeId">
        <option value="">Select assignee</option>
        <option *ngFor="let user of users" [value]="user.id">
          {{ user.name }}
        </option>
      </select>
    </div>
    
    <div class="form-group">
      <label for="priority">Priority</label>
      <select id="priority" [(ngModel)]="formData.priority">
        <option value="low">Low</option>
        <option value="medium">Medium</option>
        <option value="high">High</option>
      </select>
    </div>
    
    <div class="form-group">
      <label for="dueDate">Due Date</label>
      <app-input
        id="dueDate"
        type="date"
        [(ngModel)]="formData.dueDate">
      </app-input>
    </div>
    
    <div class="modal-actions">
      <app-button
        type="button"
        variant="secondary"
        (click)="onClose()">
        Cancel
      </app-button>
      <app-button
        type="submit"
        variant="primary"
        [disabled]="isSubmitting || !isFormValid()">
        {{ isSubmitting ? 'Creating...' : 'Create Task' }}
      </app-button>
    </div>
  </form>
</app-modal>

- HTML must follow A1 structure strictly with three-column kanban layout
- Do NOT create new components unnecessarily - reuse library components where possible
- Prefer reusable library components (Button, Card, Modal, Avatar, Badge, Input)
- HTML must be pseudo-code ONLY (NOT real framework code)
- Implement proper ARIA attributes for accessibility compliance
- Use CSS Grid for kanban columns with responsive breakpoints
- Implement drag and drop using Angular CDK
- Follow glass morphism design system throughout
- Ensure error handling with conditional rendering
- Component compilation and linting compliance required
- Real-time collaboration features are future enhancements
- Implement proper TypeScript interfaces for type safety
- Use OnPush change detection strategy for performance
- Implement proper error boundaries and fallback UI states
