# API Contract Outline
## Task Management API

### Base URL
```
https://api.taskmanagement.com/v1
```

### Authentication
- **Type**: Bearer Token (JWT)
- **Header**: `Authorization: Bearer <token>`
- **Required**: All endpoints require authentication

### Content Type
- **Request**: `application/json`
- **Response**: `application/json`

---

## Endpoints

### 1. Create Task

#### Endpoint
```
POST /api/tasks
```

#### Description
Creates a new task with validation and business logic processing.

#### Headers
```
Content-Type: application/json
Authorization: Bearer <jwt_token>
X-Correlation-ID: <uuid> (optional)
```

#### Request Schema
```json
{
  "title": {
    "type": "string",
    "required": true,
    "minLength": 1,
    "maxLength": 200,
    "description": "Task title"
  },
  "description": {
    "type": "string",
    "required": false,
    "maxLength": 1000,
    "description": "Task description"
  },
  "priority": {
    "type": "string",
    "enum": ["LOW", "MEDIUM", "HIGH"],
    "required": true,
    "description": "Task priority level"
  },
  "status": {
    "type": "string",
    "enum": ["TODO", "IN_PROGRESS", "DONE"],
    "required": false,
    "default": "TODO",
    "description": "Task status"
  },
  "dueDate": {
    "type": "string",
    "format": "date-time",
    "required": false,
    "description": "Task due date (ISO 8601 format, future dates only)"
  },
  "assignedTo": {
    "type": "string",
    "format": "uuid",
    "required": false,
    "description": "UUID of assigned user"
  }
}
```

#### Example Request
```json
{
  "title": "Implement user authentication",
  "description": "Add JWT-based authentication to the API",
```

## Validation Rules

### Field Validation
- **title**: Required, 1-200 characters, no HTML tags
- **description**: Optional, max 1000 characters, HTML sanitized
- **priority**: Required, must be one of: LOW, MEDIUM, HIGH
- **status**: Optional, defaults to TODO, must be one of: TODO, IN_PROGRESS, DONE
- **dueDate**: Optional, must be valid ISO 8601 date, future dates only
- **assignedTo**: Optional, must be valid UUID format

### Business Rules
- Due date cannot be in the past
- Assigned user must exist and be active
- Title must be unique per user (soft validation with warning)
- Maximum 100 tasks per user in TODO status

## Rate Limiting

- **Authenticated Users**: 1000 requests per hour
- **Burst Limit**: 100 requests per minute
- **Headers**: X-Rate-Limit-Remaining, X-Rate-Limit-Reset

## Security Considerations

### Input Validation
- All input fields are validated using class-validator decorators
- HTML content is sanitized to prevent XSS attacks
- SQL injection prevention through parameterized queries

### Authentication & Authorization
- JWT tokens required for all endpoints
- Token expiration: 24 hours
- Refresh token mechanism available
- Role-based access control (RBAC)

### Data Protection
- TLS 1.3 encryption for data in transit
- AES-256 encryption for sensitive data at rest
- PII data handling compliance (GDPR)
